
# SRVNet

**SRVNet** is a game-ready cross-platform networking library

***

## SRVNet Features
- **✅ Cross-platform** (Windows, Linux, others via GCC/MSVC toolchains)
- **✅ Gamedev oriented design**


## Requirements
Before using SRVNet, ensure you have the following installed:
- CMake 3.22 or higher
- Windows or Linux operating system

***

## INFO
The library is under the early stage of development
